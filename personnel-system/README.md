# Система учета персонала

Готовый проект веб-приложения для учета персонала с управлением ставками, должностями и графиком работы.

## 📋 Возможности

### Управление сотрудниками
- Добавление новых сотрудников
- Привязка к должностям
- Установка ставок:
  - Почасовая ставка
  - Дневная ставка
  - Недельная ставка
  - Месячная ставка

### Управление должностями
- Создание новых должностей
- Добавление описания должностей

### График работы
- Добавление записей в график
- Типы смен:
  - Утренняя (08:00-16:00)
  - Дневная (09:00-17:00)
  - Вечерняя (14:00-22:00)
  - Ночная (22:00-06:00)
  - Выходной
- Учет отработанных часов
- Заметки к смене

### Управление ставками
- Обновление ставок для существующих сотрудников
- Гибкое изменение любых типов ставок

## 🚀 Установка и запуск

### Требования
- PHP 7.4 или выше
- Веб-сервер (Apache, Nginx) или встроенный PHP сервер

### Запуск на встроенном PHP сервере

```bash
cd /workspace/personnel-system
php -S localhost:8000
```

Откройте браузер и перейдите по адресу: `http://localhost:8000/personnel-system`

### Запуск на Apache/Nginx

1. Скопируйте папку `personnel-system` в корневую директорию вашего веб-сервера
2. Убедитесь, что у PHP есть права на запись в папку `data/`
3. Откройте сайт в браузере

## 💡 Использование

1. **Создайте должности** - Перейдите в раздел "Должности" и добавьте необходимые позиции
2. **Добавьте сотрудников** - В разделе "Сотрудники" создайте карточки сотрудников с указанием должностей и ставок
3. **Заполните график** - В разделе "График работы" добавляйте смены для сотрудников
4. **Обновляйте ставки** - При изменении оплаты используйте раздел "Ставки"

## 🔧 Технические особенности

- **Хранение данных**: JSON файлы (не требует базы данных)
- **API**: REST-like endpoints
- **Frontend**: Vanilla JavaScript (без фреймворков)
- **Стили**: CSS3 с градиентами и анимациями
- **Адаптивность**: Поддержка мобильных устройств

## 📝 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/employees` | Получить список сотрудников |
| POST | `/api/employees` | Добавить сотрудника |
| GET | `/api/positions` | Получить список должностей |
| POST | `/api/positions` | Добавить должность |
| GET | `/api/schedules` | Получить график работы |
| POST | `/api/schedules` | Добавить запись в график |
| GET | `/api/rates` | Получить ставки |
| POST | `/api/rates` | Обновить ставки сотрудника |
