# Система учета персонала

Простой и удобный веб-сайт для учета персонала, написанный на HTML, CSS и JavaScript.

## 🚀 Возможности

### Управление сотрудниками
- Добавление новых сотрудников с указанием:
  - ФИО
  - Должности
  - Ставки в час
  - Ставки в день
  - Ставки в неделю
  - Ставки в месяц
- Просмотр списка всех сотрудников
- Удаление сотрудников

### Учет рабочего времени
- Ведение графика работы сотрудников
- Учет отработанных часов
- Различные типы дней:
  - Рабочий день (коэффициент 1.0)
  - Выходной (коэффициент 1.5)
  - Праздничный (коэффициент 2.0)
  - Отпуск (коэффициент 1.0)
  - Больничный (коэффициент 0.7)
- Фильтрация по сотрудникам и месяцам

### Отчетность
- Формирование отчетов за день, неделю или месяц
- Сводная таблица по всем сотрудникам
- Статистика:
  - Количество работающих сотрудников
  - Отработанные часы
  - Рабочие дни
  - Общая сумма начислений

## 💾 Хранение данных

Данные сохраняются в localStorage браузера, поэтому они будут доступны даже после закрытия страницы (в том же браузере).

## 🛠️ Установка и запуск

1. Скопируйте папку проекта на ваш компьютер
2. Откройте файл `index.html` в любом современном браузере

Или используйте локальный сервер:

```bash
# Python 3
python3 -m http.server 8080

# Затем откройте в браузере
http://localhost:8080
```

## 📝 Использование

### Добавление сотрудника
1. Перейдите на вкладку "Сотрудники"
2. Заполните форму добавления сотрудника
3. Нажмите кнопку "Добавить сотрудника"

### Ведение графика
1. Перейдите на вкладку "График работы"
2. Выберите сотрудника из списка
3. Укажите дату, количество часов и тип дня
4. Нажмите "Добавить в график"

### Формирование отчета
1. Перейдите на вкладку "Отчеты"
2. Выберите сотрудника (или "Все сотрудники")
3. Выберите период (день, неделя, месяц)
4. Укажите дату
5. Нажмите "Сформировать отчет"
